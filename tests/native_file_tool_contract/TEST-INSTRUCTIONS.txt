Offline regression tests only; do not install these tests into a live user profile.

Apply source-contract.patch to a disposable copy of the final composed native tree.
Apply source-tests.patch to that same disposable copy; it supplies exactly these
self-contained files (no private artifact imports):
  tests/hermes_cli/ordinary_file_contract_fixtures.py
  tests/hermes_cli/test_ordinary_file_tool_contract.py
  tests/gateway/test_tool_disclosure_cache_refresh.py
The native interpreter must have the native runtime dependencies, pytest and
pytest-asyncio installed. No model credentials or network are needed.

From the directory containing portable-test-bootstrap.py:
  export FRIDAY_TEST_NATIVE=/absolute/path/to/disposable-final-native
  export FRIDAY_TEST_SANDBOX=$(mktemp -d)
  export FRIDAY_TEST_PYTHON=/absolute/path/to/python-with-native-and-pytest
  export FRIDAY_TEST_BOOTSTRAP="$PWD/portable-test-bootstrap.py"
  export FRIDAY_TEST_WRAPPER="$FRIDAY_TEST_SANDBOX/test-python"
  python3 - <<'PYWRAPPER'
import os, shlex
from pathlib import Path
keys = ('NATIVE','SANDBOX','PYTHON','BOOTSTRAP','WRAPPER','EXTRA_SITE')
values = {'FRIDAY_TEST_'+k:os.environ.get('FRIDAY_TEST_'+k,'') for k in keys}
wrapper = Path(values['FRIDAY_TEST_WRAPPER'])
wrapper.write_text('#!/bin/sh\n'+''.join('export '+k+'='+shlex.quote(v)+'\n'
                  for k,v in values.items())+
                  'exec "$FRIDAY_TEST_PYTHON" -E -B "$FRIDAY_TEST_BOOTSTRAP" "$@"\n')
wrapper.chmod(0o700)
PYWRAPPER
  HERMES_PYTHON="$FRIDAY_TEST_WRAPPER" HERMES_TEST_WORKERS=2 HERMES_TEST_FILE_RETRIES=0 \
    "$FRIDAY_TEST_NATIVE/scripts/run_tests.sh" \
    tests/hermes_cli/test_ordinary_file_tool_contract.py \
    tests/gateway/test_tool_disclosure_cache_refresh.py

The generated wrapper pins these supplied paths across native env -i cleanup.
The bootstrap patches Path.home and sets HERMES_HOME, all XDG locations, runtime,
temp and gateway lock directories before importing any native modules. It keeps
its interpreter wrapper across runner subprocesses and clears plugin autoload.
Optional FRIDAY_TEST_EXTRA_SITE adds a dependency site-packages directory when
pytest is supplied separately from the runtime environment. The source test files
and portable bootstrap contain no fixed developer paths. Keep the sandbox as
evidence until its results are consumed, then remove that exact directory.

The cached-agent fixture substitutes only model construction. No model request,
Telegram transport or installed-runtime activation is exercised. The independent
review adds 14 author-independent controls; overlapping suites are counted separately.
