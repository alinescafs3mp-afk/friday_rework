Offline Source85 web runtime, failure presentation and transcript privacy checks.

The source delta contains seven existing native files. The web/browser children
activate the already committed PM dependency generation after trusted input and
without resetting their deadline. Ordinary web failure copy withholds private
diagnostics and distinguishes confirmed from unconfirmed cleanup. Transcript
projection removes private receipt-only rows without rewriting canonical history;
repeated-heal diagnostics remain limited to the operator CLI audience.

Use disposable source trees and dependencies already available locally. Set
absolute FRIDAY_TEST_PROJECT, FRIDAY_TEST_NATIVE, FRIDAY_TEST_PREVIOUS_NATIVE,
FRIDAY_TEST_PYTHON and a fresh FRIDAY_TEST_SANDBOX. PREVIOUS_NATIVE must be the
exact Source84 predecessor: two negative controls execute its original children.
NATIVE must be Source85, or the exact Source84 tree with the seven Source85
files under FRIDAY_TEST_NATIVE_OVERLAY. Verify those seven files against the
published ordinary-web-runtime-history-manifest.json before running. For a
complete Source85 tree leave OVERLAY empty. EXTRA_SITE may name an existing
pytest site-packages directory if the native interpreter needs it.

The published Source84 bootstrap and fixture plugin are reused. They establish
Path.home/HERMES_HOME/XDG/temp isolation before native imports, deny network/DNS,
and fence Python writes to the supplied sandbox. HOME is isolated explicitly
by the command. The fixture plugin disables installed credential-host bootstrap
only for gateway specimens built with __new__. Cold children use real PM code
in generated homes and terminate at a synthetic dependency consumer; they do
not reach a provider, browser namespace or credential store.
