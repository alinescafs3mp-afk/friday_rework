# Bounded final evidence: prospective source repair

The [consumed G7 run](../a0-g7-runtime-failure/README.md) remains FAIL. Its parent tried to inline 545 complete transport records into a final report limited to 64 KiB; the refusal repeated the same large inventory and failed too. Normal owner exit followed separate verified cleanup and diagnostic preservation.

This is an inert source proposal, not an installed or newly authorized candidate. [The helpers](compact_helpers.py.inert.txt) and [minimal parent diff](serialization.diff.txt) retain the 64 KiB output limit. Large snapshots may reference an already-durable complete phase only after exact private-file, hash, parent, session and full-content checks. Both original inventories remain recoverable by JSON pointers. The raw in-memory snapshot remains intact; no records are sampled or truncated and no new large file is written. A 32 MiB bound applies only to reading that existing phase. Original memory, clocks, release gates and once-only failure latches remain unchanged.

The refusal report uses inventory digests/counts, typed status and exact saved-evidence references. Missing or mismatched evidence yields STOP_UNCONFIRMED and retains custody; it cannot grant release. A failed save is never retried. [Independent changed-source review](independent-review.json) accepted R2 after 92 checks. R1 had been rejected because Python equality conflated true with 1 and integer with float; R2 compares strict finite canonical JSON and preserves those distinctions. Consumers must understand the V2 complete-reference representation; earlier V1 source acceptance is not transferred. Timeout reverse-order enforcement remains a separate unresolved design requirement.

[Offline results](offline-result.json) record 46 checks against the actual saved phase: the 18,785,727-byte full value becomes an 869-byte complete reference, and the late-refusal report is 3,600 bytes. Controls cover wrong path/hash/session/parent/phase, changed or missing transport/bus data, symlink/mode violations, absent captures, save failures, no repeated cleanup/save and unchanged release control flow. These checks establish serialization behavior only; they neither replay nor accept G7.

[The actual check program](test_offline.py.inert.txt) is published with an unconditional inert guard and its private input root replaced by an unbound marker. Raw host captures, owner grants and process identities are omitted. Original private-code hashes in the result are provenance, while [the manifest](manifest.json) binds normalized public files. This analysis package does not mint a future runtime generation or authorize any retry.
