# Source candidate: ordinary native terminal

This private normal25 delta is implemented source, with 74 selected-source-body
controls using explicitly inert fixtures. It is not enabled, imported through
full Hermes, independently accepted, or executed through a native runtime.
SAFE remains unchanged. Astra owns composition, independent review and admission.

The scoped local factory requires current authenticated UserScope, the native
caller, finite ORIGINAL native run deadline and an explicit operator-owned
`terminal.scoped` allocation. Missing scope/policy/clock, another backend, stale
cache, unsupported mount or capacity refuses before shell bootstrap. No settings
were installed by this assignment. Suggested allocation schema is exactly:
`local_only, cpu_quota_pct, memory_bytes, tasks_max, tmp_bytes, max_active`;
CPU/memory/tasks/tmp are aggregate per-profile limits, split immutably per slot.
Already admitted allocations are counted before another command can launch.
Startup/settlement reserves require more than eight seconds of admissible budget.

Foreground bootstrap/execute and background/PTY share ProcessRegistry's mandatory
per-command Type=exec transient service + bwrap + one-shot exec gate. Checkpoint
intent/launch uncertainty/native identity/release intent are durably synchronized
and read back before permit. Exact unit/invocation/cgroup inode/MainPID birth,
resources, activation clock and original boot/deadline are retained. No login rc,
ambient credentials, host fallback, PTY-to-pipe or generic command retry exists in
the scoped path. Native bash snapshots and readers remain the shell engine.
Background uses a separate stable snapshot; strict scoped snapshots refuse a
missing/broken source and background output omits the private cwd marker.

Foreground promotion keeps the same ProcessSession, Popen, service/invocation,
output custody and clock. The old drain must cease first. Input uses current
original authority/task/session and bounded nonblocking writes; a partial write
reports bytes and never retries the command. Handoff keeps original custody and
separately records the verified native parent owner; agent stop custody transfers
with it. Trusted exact-owned stop remains possible after revoke. EOF never proves
cessation. Natural/deadline/cancel/revoke cleanup must observe the old wrapper and
whole cgroup; uncertain state retains custody/capacity and prevents replay.

Recovery retains the same validated checkpoint intent, status and artifacts,
including pre-Popen intent. It cannot recreate a grant, pipe or PTY. Malformed
custody blocks admission without rewriting its evidence. Different boot remains
unconfirmed; no new deadline, automatic restart or fresh execution is inferred.

Native local methods were factored intact into the registry's new terminal
sibling; its public APIs stay inherited and the oversized facade shrank. Its
existing registry mutex becomes RLock so strict checkpoint readback can run inside
the same custody transaction. This changes copied source only, never live locks.
Astra must resolve the user_authority/checkpoint/retained overlaps with her
separate principal candidate and independently check all composed bytes. Parent
principal guards remain required, particularly public kill and retained delivery.

Required real tests, all **NOT_RUN**:

- Actual full native import/build/static gate on the final composed/pinned source;
  scoped factory and lazy file first-use, missing authority/policy/deadline/clock.
- Native command + file transformation; exact exit/output; cd/export/function/alias
  across calls; missing cwd and snapshot refusal; native approval deny/approve/force.
- Background pipe output/tail/retained receipt, write/submit/close and backpressure;
  true PTY/isatty/controlling TTY, REPL state, EOF/Ctrl-C/resize; failed PTY startup
  has no pipe fallback or duplicate command.
- Foreground yield/adoption under output flood: same handle/unit/invocation/clock,
  exactly one reader, no duplicate output/notification; background snapshot isolation.
- Principal/profile/generation/task/session guessed handles and ambiguous prefixes;
  live/finished/retained reads/mutations; revoke/re-enable; authorized parent handoff.
- Credential env/file sentinels, other profile/workspace, hardlink/symlink/mount
  races, host proc/cgroup/control socket/SSH agent/sudo, host loopback and abstract
  socket escapes; independent native web/delegation continues through its own path.
- Detached setsid/double-fork/SIGTERM-ignoring descendants; explicit kill, active
  and idle /stop, /new, revoke and deadline; gateway SIGKILL/down beyond original
  deadline; observed original cgroup empty, unrelated service intact, no replay.
- Faults at intent/Popen/READY/show/checkpoint/release/reader transitions; disk
  full/fsync/readback errors, unavailable user bus, wrong/duplicate manager fields,
  changed invocation/cgroup/birth/boot, late activation, blocked stdin and failed stop.
- Actual aggregate CPU/memory/tasks/tmp limits, output flood and startup/stop wedge;
  no overcommit on a narrowed allocation and no fresh grant on adoption/recovery.
