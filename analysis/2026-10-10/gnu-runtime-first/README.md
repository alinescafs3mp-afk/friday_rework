# Первый GNU runtime — 10.10.2026

Два найденных несоответствия исправлены и независимо проверены: consumer использует актуальный native SHA; исходный caller удерживает quality lock до собственного выхода, а producer и consumer различают удержание и последующее освобождение. [Восемь полных исходников](source-index.json) опубликованы как инертные материалы для анализа. В них заменены только private lock path и filesystem identity; обратное восстановление исходных байт и AST проверены. Неопределённые PUBLIC_LOCK_* намеренно не являются рабочей конфигурацией. Текущее тело finite_trace также включено: прежняя версия отличалась проверкой аргументов и исходного времени. Остальные исходники доступны в прежних срезах; это не самостоятельный установочный пакет.

После source review выполнена одна ограниченная реальная попытка. [Результат](outcome.json): GNU сделал fork, но завершился с кодом 125 до подтверждения таймера. Child оставался остановленным и был завершён штатной уборкой; target **NOT_RUN**. Журнал пуст, конкретная причина отказа на этом срезе ещё не установлена. Три отрицательных проверки выделения CPU и исходного deadline сработали; полного успеха девяти GNU controls нет.

Caller получил конечный wait4: CPU owner/tree 0.651458 с. Mode accounting сохранило false и расхождение 1 мкс между raw rusage и children delta; эти значения не подменены нулём или успешной приёмкой. Caller CPU 1.397124 с на момент записи учитывается отдельно; последующий write/exit tail неизвестен. Попытка закрыта и потреблена, повтор не разрешён.

Первое внешнее наблюдение через 19.578491 с подтвердило отсутствие caller, owner и GNU и освобождение блокировки; оно пропустило identity четвёртого процесса. Terminal wait4 уже содержал его завершение. Дополнительная read-only проверка всех четырёх identities выполнена после исходных 180 с и подтвердила отсутствие всех процессов. Она не продлевает запуск. Отдельной записи return value native close нет; exit1 не выдан за close0.
