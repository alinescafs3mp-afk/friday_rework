# Ordinary process authority source slice

This implements retained principal, profile and admission-generation identity in the existing Hermes process registry. The identity travels through native checkpoints and completed-result receipts. The process tool resolves a caller-visible process before refreshing or acting on it, uses its canonical ID, checks the existing tool allowlist, and rechecks authority after a blocking operation. Parent/child handoff retains the same identity and checkpoints ownership changes. Trusted cleanup keeps its existing API so revocation cannot prevent stopping task-owned processes.

The unchanged exporter composed 26 layers and 17,640 files. All prior 25 layers remain exact; this slice changes two existing files and adds one helper. Fifty finite source controls passed, including foreign and stale-generation refusals, all process actions, post-wait revocation, retained-result loading and cleanup after revoke. They execute selected actual source bodies with explicit inert admission and I/O fixtures. Native modules, installed services and runtime tests were not run.
