# Reusable daily Git inventory

The [standalone program](../../../scripts/daily-analysis/daily_finalizer.py) produces a period index from explicit immutable base and end commits. It retains every parent edge and intermediate add, rename, deletion or reversal, even when absent from the final net diff. It validates public manifests and hash references, reports local link gaps, and refuses invalid ancestry, bad hashes and output collisions. Inspected source is never imported or executed. [Usage and limits](../../../scripts/daily-analysis/USAGE.txt) describe the resource bounds and exact validation scope.

[Observed results](observations.json) retain the actual review sequence. The initial program passed eight author and eight independent Git fixtures. Assembling a prior provisional report beside newer source exposed three false hash mismatches; historical range fields were then explicitly classified as provenance. Review of that correction passed nine provided and five independent checks but rejected a separate missing-current-artifact case: a generated index without its integrity report incorrectly returned PASS.

The current correction makes the typed current integrity reference mandatory while preserving historical field handling. [Ten actual Git fixture cases](../../../scripts/daily-analysis/test_daily_finalizer.py) pass, including seven new refusal subcases and one positive control. The exact reviewer missing-target reproduction now refuses without creating output. Independent review accepted this exact final correction: all ten Git fixtures and [24 additional current-reference controls](current-reference-observations.json) passed, including 23 refusals without output and one valid current artifact beside stale historical hashes. The [actual independent check program](../../../scripts/daily-analysis/current_reference_checks.py) is included. Earlier passed cases remain associated with their original source hashes.
