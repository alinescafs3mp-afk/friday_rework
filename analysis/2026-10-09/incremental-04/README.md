Incremental-04 contains inert authored sources, framework patches, source plans and selected source-review outcomes from seven closed packages. Start with [WORKLOG.md](WORKLOG.md), [coverage.json](coverage.json) and [outcomes.json](outcomes.json).

Sources end in `.txt` and symbolic local paths are deliberately non-executable. [source-index.json](source-index.json) binds originals, transformed bytes, predecessor identities and upstream patch bases. [plans-index.json](plans-index.json) marks historical plans and their unsupported owner assumptions. [metadata-reconciliation.json](metadata-reconciliation.json) accounts for selected manifest/source/map paths by content. [timeline.json](timeline.json) preserves unknown duration as null. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) links exact already-published licenses.

No private handoff, original task payload, credential, full binding map or raw runtime log is included. Publication does not grant runtime execution, satisfy a gate or accept a journey. Later active repairs and the final daily checkpoint remain outstanding. Only the root integrator may publish this prepared directory.

[process-decisions.json](process-decisions.json) adds 36 selected historical integration and publication records: 28 root receipts, six publication preparations/reviews, the verified closure of an unsuccessful parent before any native build, and one cancelled incomplete review. They preserve original timestamps and unknowns; overlapping durations are not added. The lifecycle reconciliation is an additional coverage check, not a claim that the whole daily period is complete.
