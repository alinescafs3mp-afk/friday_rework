# Incremental-08: joined source repairs and first two native builds

09.10.2026. Подготовленный аналитический срез после `fc765b90fffd6124424212b502a4b8654078030a`. Ежедневный baseline `00c3b825260792b834e7f2aecf19eaabaa02935d` сохраняется.

На точном объединённом исходнике независимо закрыты J1/R1/R2. Сборки `finite_birth.so` и `gnu_arm_shim.so` впервые действительно выполнены: обе PASS, без загрузки библиотек. ABI/F6 и установленный продукт (семь journeys, четыре web-возможности) остаются UNACCEPTED. Этот срез не подключает код к продукту и не даёт runtime grant.

J1: все 123 внутренних ссылки (86 вложенных и 37 manifest) соответствуют фактическим байтам. Внешние 31 386 записей input map сохранены без повторного исполнения корпуса. R1: необратимый latch сохраняет ошибки native CPU/deadline/delivery/rollback после положительного spawn и проверяется перед единственной записью B gate. R2: восстановление PID/Custody выполняется отдельно до попытки kill; ошибка доставки не пропускает доступный wait4/harvest исходного deadline. Это закрытие исходных контрпримеров на уровне кода; атомарность signal/write, реальная доставка и final cleanup требуют ABI/F6.

В [source-index.json](source-index.json) — полные тела шести изменившихся Python-файлов и двух JSON source specifications. Три Python-файла меняют логику, ещё три отличаются только переносом корня candidate; эти различия явно учтены. Все пять pin maps отражены полными внутренними таблицами before/after; внешний неизменный корпус исключён. [coverage.json](coverage.json) учитывает каждый из 38 файлов, включая path-only изменение приватного policy record без его публикации. [internal-pin-reconciliation.json](internal-pin-reconciliation.json) содержит все 123 внутренних ссылки. Неизменные C-файлы и GNU version script доступны в [предыдущем срезе](../incremental-07/source-index.json).

Расширение `.txt` делает экспорты инертными. Комментарий-префикс и символические пути/идентичность lock обратимы по защищённой карте; полные тела и семантика кода сохранены. Приватные policy records, operational bindings и внешний корпус не публикуются, поэтому это не готовый runtime bundle. SHA исходника и SHA публичного текста различаются и записаны отдельно. Исторические поля NOT_COMPILED/UNREVIEWED внутри исходных JSON сохранены: позднейшие review/build наблюдения находятся отдельно, исходный снимок не переписан.

[findings.json](findings.json) разделяет закрытые ошибки и оставшиеся условия. [build-outcome.json](build-outcome.json) сохраняет argv с символическими путями, hashes, реальные compiler/header/link counts, выходы, время и ELF-наблюдения. Первая read-only preflight ошибка regex приняла `-linux` в пути за `-l`; исправлена граница токена, успешные preprocess/driver наблюдения использованы повторно. Это не неудавшаяся DSO-сборка и не retry. Оба compiler exit 0, stderr пуст, группы завершены; 347 входов проверены до/после. Результат elapsed — 58.222945 секунды из исходных 600. Подготовка не запускает компилятор повторно и не экспортирует бинарники.

[outcomes.json](outcomes.json), [STATUS.md](STATUS.md) и [WORKLOG.md](WORKLOG.md) сохраняют исходные часы и границы. Активные позднейшие binary/primitive reviews находятся за пределами среза. Отдельный пакет восьми primitive controls ещё не является полным F6. G20 FAILED137 остаётся consumed/closed без повтора; A0/TS/UC1/browser stops и old product OFF сохранены.

Публикацию выполняет единственный интегратор после независимой проверки [ALLOWLIST.json](ALLOWLIST.json) и [MANIFEST.json](MANIFEST.json). Самопроверка упаковки не является независимой приёмкой кода, бинарников или продукта. [Notices](THIRD_PARTY_NOTICES.md) и [закреплённые upstream references](upstream-source-references.json) сохранены без сетевых действий.
