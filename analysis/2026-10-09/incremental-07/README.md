# Исходный срез F4/F5: native birth и GNU bootstrap

Завершённые исходники F4 и F5 сохранены для анализа вместе с тремя незакрытыми дефектами R1/R2/J1. Обе реализации **не приняты**. Финальная сборка, загрузка и F6 — **NOT_RUN**; все 7 journeys и 4 web — **UNACCEPTED**, прежняя Friday выключена, G20 закрыт без повторного запуска.

F4 содержит шесть полных авторских файлов: native clone3/exec в том же caller, pidfd с рождения, native обработчик исходного дедлайна и Python-обвязка. F5 содержит GNU shim/map, TraceCustody и изменённые owner/launcher/mode/test bodies: барьер после exec, полная SEIZE до выпуска, удержание mode, DETACH GNU до его штатного arm60, строгая запись успешного arm и единый wait4/accounting. В этой подборке две исходные реализации хранятся раздельно; финального объединения здесь нет.

[Исходный индекс](source-index.json) перечисляет 17 полных файлов: 12 Python, 2 C, 1 linker map и 2 JSON.

Фактические отказы перечислены в [findings.json](findings.json). R1 допускает выпуск gate после собственного CPU endpoint и ошибки доставки сигнала; R2 теряет доступный путь восстановления PID/custody при исключении kill_root. Это статические контрпримеры, не наблюдавшиеся live-инциденты. J1 — три устаревшие вложенные ссылки SHA среди 76 внутренних записей F5, обнаруженные до эффектов. Успешные авторские syntax/static проверки эти дефекты не закрывают.

Состояние и результаты: [STATUS.md](STATUS.md), [outcomes.json](outcomes.json), [static-observations.json](static-observations.json), [WORKLOG.md](WORKLOG.md). Полный перечень подготовленных native контролей сохранён в [prepared-controls.json](prepared-controls.json), все NOT_RUN. Исходные 180 wall / 45 CPU / root6 / AS2GiB / affinity0,1 / GNU60 + closure60, 11 режимов, 277/831, отдельные 38/114, paired512 и deny125 не сокращены.

Все исходники имеют суффикс `.txt` и неисполняемые права. Пути заменены символическими метками, две точные host lock identity tuples — именами LOCK_DEVICE/LOCK_INODE/LOCK_UID/LOCK_GID. Тело проверок сохранено, подстановки обратимы по приватному доказательству. Эти символы намеренно не определены. Исходные SHA относятся к приватным оригиналам, экспортные — к опубликованным байтам; никаких разрешений на исполнение из этого не следует.

[Сводка input maps](input-inventory-summary.json) сохраняет все внутренние записи и точные счётчики исключённых внешних записей. Внешние пути/корпус и полные исполняемые pins не публикуются. [coverage.json](coverage.json) объясняет судьбу каждого изменённого файла. Исторический F5 metadata сам описывает ещё не выполненный F4 join; его полный текст не является текущим разрешением.

[MANIFEST.json](MANIFEST.json) покрывает все остальные файлы среза, включая [ALLOWLIST.json](ALLOWLIST.json); сам манифест закреплён внешним результатом подготовки. [preparation-checks.json](preparation-checks.json) и [privacy-scan.json](privacy-scan.json) относятся только к упаковке. Ссылки и notices — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Предыдущий [incremental-06](../incremental-06/README.md) и daily baseline сохраняются; этот промежуточный материал входит в следующий суточный период.

Следующий необходимый результат — отдельный объединённый successor с исправлениями R1/R2/J1, независимой проверкой изменённых байтов и зависимостей, затем точная сборка двух DSO/ABI и полные F6 controls. Активные ремонты и подготовка F6 лежат вне этого среза.
