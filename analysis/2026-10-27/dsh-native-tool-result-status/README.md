# DSH native tool-result status compatibility

The pinned native producer emits `tool_result.status` values `completed` and `error`; the old DSH parser accepted `completed` and `failed`. A valid, owned tool error therefore stopped parsing. This one-line source change accepts the producer vocabulary. Tool errors remain recoverable tool results: the native turn reason, final event, matched calls/results, process outcome and quiescence still govern completion. Foreign and duplicate results, obsolete/unknown statuses and invalid terminal ordering remain rejected.
