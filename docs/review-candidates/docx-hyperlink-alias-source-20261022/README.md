# DOCX replacement: hyperlink text and XML identity aliases

Status: **UNCONNECTED / NOT_RUNTIME_ACCEPTED**. This source archive extends the [opaque-anchor source candidate](../docx-opaque-anchor-source-20261020/README.md). It contains the exact independently reviewed helper and a cumulative patch against that predecessor. Installation, product integration and ordinary post-install retesting remain pending.

The B24 implementation adds replacement wholly inside each direct `w:hyperlink` paragraph child. Only its direct runs participate, in consecutive groups separated by non-run XML barriers. Matches never span direct paragraph runs and a hyperlink, two hyperlinks, or nested wrappers. Hyperlink attributes, relationship identifiers and targets, run formatting and opaque XML retain the established preservation policy. Original non-overlapping matches are processed once; inserted replacement text is never rescanned within a matching call.

Independent B24 review accepted the changed matching area but rejected unconditional task completion because the inherited paragraph iterator could revisit the same XML through merged table cells or linked headers and footers. B26 closes that source defect by retaining XML identity references for each traversal, yielding a paragraph only at its first encounter and pruning repeated merged-cell subtrees and shared header/footer parts. Distinct XML paragraphs with identical text remain distinct. Traversal order and the header/footer option retain their previous meaning. The extracted matching algorithm and opaque-anchor ownership policy remain unchanged.
