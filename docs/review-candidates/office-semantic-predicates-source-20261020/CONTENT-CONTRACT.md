# Office semantic content contract v1

Private, source-only stdlib reader. `inspect(data: bytes, format: str) -> dict` parses exact `docx|xlsx|pptx`; `grade_bytes(data, format, requirements: list, before: bytes|None=None) -> list[str]` returns successful predicate descriptions. Any failure raises `ValueError`; unsupported features/operations raise distinct `Unsupported(ValueError)`. No execution, rendering, formula calculation, Office/network calls or extraction. DOCX paragraph and table order are each checked separately; their relative interleaving and full body/layout order are not represented and cannot be accepted by these predicates.

Requirements are a nonempty list (max 256) of unique dictionaries. Unknown keys/ops, bool-as-int, nulls where undeclared, duplicate requirements, invalid selectors and empty selected-cell or preservation lists fail closed. Exact collection checks include order and duplicates; equals:[] may substantiate absence. Indices below are zero-based except PPTX `slide` (one-based). All strings are bounded and compared verbatim unless a normalization is explicitly stated.

Closed requirement schemas (only the indicated keys are accepted):

* `{"op":"docx.paragraphs","equals":["paragraph", ...]}`: all direct body paragraphs, including blank paragraphs, exact order. Run text/tab/break content concatenated; field instruction text excluded.
* `{"op":"docx.tables","equals":[[["cell", ...], ...], ...]}`: all direct body tables, row/cell text (paragraphs separated by newline), exact order. Nested tables and ambiguous tracked/alternate content are unsupported.
* `{"op":"docx.hyperlinks","equals":[{"text":"label","target":"https://example.test/"}, ...]}`: body links in occurrence order. Internal anchors represented as `#anchor`.
* `{"op":"docx.fields","equals":[" PAGE ", ...]}`: simple/complex field instruction strings, exact concatenated instruction bytes as Unicode, in occurrence order; no field result calculation claim.
* `{"op":"docx.images","equals":["<lowercase SHA256>", ...]}`: actual body drawing image relationships in occurrence order; selected image bytes only, not layout/rendering.
* `{"op":"xlsx.sheets","equals":["Sheet1", ...]}`: actual workbook relationship order, exact sheet names.
* `{"op":"xlsx.cells","sheet":"Sheet1","equals":[{"address":"A1","type":"text","value":"hello","formula":null}, ...]}`: selected existing cells, exact typed value and literal formula. Addresses unique and canonical uppercase. `type` is `text|number|boolean|error|date|blank`; value is respectively string, canonical finite decimal string (no exponent/trailing zeros, `-0`→`0`), bool, string, ISO lexical string, null. Formula is null or nonempty literal string, without leading `=`; cached value is observed only, never calculated. Blank absent cells do not equal explicit cells.
* `{"op":"xlsx.hyperlinks","sheet":"Sheet1","equals":[{"ref":"A1","target":"https://example.test/"}, ...]}`: actual worksheet link order; internal locations represented as `#location`.
* `{"op":"pptx.slides","equals":[["text paragraph", ...], ...]}`: actual presentation relationship order; all declared shape-tree text paragraphs in order (including table-cell text); speaker notes are excluded; visibility, hidden state and off-slide positioning are not evaluated.
* `{"op":"pptx.tables","slide":1,"equals":[[["cell", ...], ...], ...]}`: selected slide's tables in occurrence order.
* `{"op":"pptx.hyperlinks","slide":1,"equals":[{"text":"label","target":"https://example.test/"}, ...]}`: actual text-run hyperlinks in occurrence order.
* `{"op":"pptx.images","slide":1,"equals":["<SHA256>", ...]}`: actual selected slide image references.
* `{"op":"preserve.parts","parts":["word/media/image1.png", ...]}`: compare selected existing package-part SHA256 against parsed `before` of the same format.
* `{"op":"preserve.view","selectors":["/docx/paragraphs/0", ...]}`: exact selected normalized values versus `before`. Selectors use simple slash-separated dict keys/list indices (no escaping, wildcards, negative indices, metadata/part paths). Allowed roots `/docx`, `/xlsx/sheets`, `/pptx/slides`; selecting existing normalized collection/value only. Dict selectors accept actual keys; cell addresses are canonical.
* `{"op":"xlsx.calculation", ...}` (any shape) and any unknown op raise `Unsupported`; real recalculation is deliberately unsupported.

`inspect` view includes `format`, `main_part`, `parts` mapping part names→SHA256, plus one format key. DOCX contains `paragraphs,tables,hyperlinks,fields,images`. XLSX contains `sheets`, each `name,part,cells,hyperlinks`; cells map addresses to `type,value,formula`. PPTX contains `slides`, each `part,text,tables,hyperlinks,images`. All external relationships must be HTTPS hyperlinks referenced by content and represented in that view. In grading, each such link collection must be checked explicitly with the corresponding exact hyperlinks predicate (preservation alone does not authorize external links).

Safety: input ZIP max32MiB,1024 members per archive,16MiB per member,48MiB total uncompressed including embedded packages, ratio<=200; aggregate embedded archives max2048 members and64MiB packaged/compressed bytes. ZIP64, comments, overlays, multidisk flags/count mismatches, encrypted/duplicate/symlink members fail closed; stored/deflated only; CRC checked while bounded reads; no extraction. XML max8MiB/member,24MiB aggregate bytes,250000 aggregate elements,500000 attributes,16MiB text/attribute characters, depth128,65536 elements/member. Bounds propagate into safely parsed one-level embedded chart XLSX. All XML (including UTF16/32 declarations) rejects DTD/entities and is parsed incrementally with stdlib ElementTree. Package content types and official absolute relationship Type URIs are checked; actual root officeDocument linkage, workbook worksheet linkage and presentation slide linkage determine content. Duplicate semantic containers fail closed. Macros, active/OLE/unsafe external content, active document fields/formulas, unsupported markup, ambiguous alternate/tracked content, unsupported formula encodings, and unknown relationship types fail closed. Main Office namespaces are transitional OOXML only; strict OOXML is unsupported. Styles/layout/rendering, headers/notes, computed cell values, chart meaning and semantic equivalence outside declared predicates are not accepted claims. Content in unselected parts can only be protected by exact `preserve.parts`.
