# Qwen: агрегатный baseline

Все 12 разных заданий и три повторных якоря закончены 23 октября 2026 года. Машинный PASS — 5/12; с внешней оценкой русской прозы по исходной рубрике — 7/12. Это оценка Codex, не слепая человеческая экспертиза. Завершённый baseline содержит неуспешные исходы и не является приёмкой продукта.

[Наблюдения](OBSERVATIONS.md) публикуют только агрегаты, версии, ограничения и историю исправлений инфраструктуры. Задания, prompts, fixtures, решения, expected outputs, скрытые assertions, oracles и raw transcripts здесь не публикуются. Приватный полный архив сохранён отдельно; его передачу нельзя считать публичной воспроизводимостью.

Qwen оставлен работающим; все собственные запросы и sandbox завершены и очищены. Ornith не запускался, сравнения моделей пока нет. Для этой публикации baseline и live-проверки не повторялись.
