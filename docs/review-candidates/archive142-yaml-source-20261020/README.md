# Archive 142: fixture and YAML source observation

This is an inert source archive of three fixture modules and one YAML module, with four exact original-to-final patches. It preserves the observed candidate, including a confirmed MED defect. These files are not installed, connected to the product, or accepted as a release. Snapshot names end in `.py.inert.txt` and avoid pytest discovery; existing repository tests are unchanged.

The fixture changes defer unused template publication, keep per-test homes fresh, and locate the registered archive route through current FastAPI route contexts. The YAML change optionally uses an installed C syntax parser with the native ruamel YAML 1.1 resolver and constructor, with fallback for selected syntax and depth cases. No shared document or HOME cache is introduced. `SOURCE.json` pins all preimages, snapshots and patches. Three preimages are public repository files at the recorded commit; the original YAML preimage is hash-pinned but is not included. Patches retain their original relative path labels and require those exact preimages. They are not installation instructions.

One exact private-overlay archive observation selected 142 cases. Measured external duration was 99.08428532699327 seconds under the original 100-second cap, leaving 0.9157146730067325 seconds. This narrow observation does not establish timing robustness. An earlier, distinct YAML candidate reached phase/session completion but failed its external cap at about 100.016 seconds with process exit 137; that failure remains historical. Scoped final controls passed 100 selected cases plus a separate 3-case URI-percent check. Their coverage overlaps other sets and must not be summed as unique catalogue cases. These observations were reused from existing checked evidence; preparing this archive did not rerun them.

**Open MED: YAML exception contract.** Constructing `SyntaxLoader(document)` for an unpaired-surrogate Python `str` can raise `UnicodeEncodeError` instead of the original ruamel `ReaderError`/`YAMLError`. This bypasses existing `except yaml.YAMLError` handlers. Independent review confirmed two such cases; eight other encoding/error controls agreed. Source-wide compatibility PASS is withheld. Any repair will have different bytes and needs its own affected-area checks and required gates.
