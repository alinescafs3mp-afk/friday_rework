# Source97 lock-policy budget: partial analysis archive

**PARTIAL ANALYSIS ONLY.** These files preserve a coherent source delta and the observed failures for review. Source composition passed; the complete short regression chain and full gates have not passed. This archive grants no installation, activation, runtime or release acceptance.

The native delta caches only raw parsed configuration keyed by the bytes read on each call. It bounds retained byte keys to four entries of at most one MiB each, copies parsed mappings before use, and keeps environment expansion and managed configuration evaluation current. It moves authority checks outside cumulative lock-wait accounting while preserving checks before every acquisition attempt and enforcing the original absolute deadline. The incremental operator delta applies the matching read-only acquisition behavior. These are descriptions of the archived code, not claims of completed runtime qualification.

The additional regression module contains 12 parameterized semantic cases across 10 test functions. It covers fresh configuration bytes, environment/managed-layer freshness, caller mutation, read refusal and deletion, large-file cache bypass, current operator policy, lock contention, exhausted allowances, and absolute deadlines. Its deterministic clock separates validator work from wait accounting; it cannot establish real wall-clock performance. A separate actual component run passed all 12 cases and 36 phases plus nine receiver negative controls within the original 60-second whole budget (19.936118296 seconds total; collection 3.492 seconds and execution 7.959 seconds). The durable receipt and successful return were observed within that clock; recorded input trees and system state were unchanged and helpers/namespaces cleaned up. This component is distinct from the original supplemental12 group described below, and its pass does not close stopped19 or any full gate.

The separate fixture repair is exactly one hunk. The fixture intentionally omits a gateway mapping key, so it uses the existing complete-state replacement API and verifies the resulting mapping. The afterimage is 692 bytes larger. It preserves product guards and changes only fixture construction.

Recorded composition verified 97 layers and 17,760 files in 14.859960288 seconds under the original 420-second budget. The first short attempt recorded 10 passed and two failed supplemental cases due to the fixture writer choice. After correction, all original 12 supplemental cases passed, then stopped19 timed out at its unchanged 35-second limit: 10 cases completed, with setup and call of the next case observed before interruption. Startup10, the short-chain nine receiver controls and full350/focused222 remain unrun. The separate component receiver controls above do not replace this missing chain evidence. The graph remains partial analysis; a passed prefix does not close a failed group.
