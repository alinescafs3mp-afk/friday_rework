# Source112: фактическая установка и результат новой беседы

Срез на 23.10.2026, около 03:10 МСК: Source112 с 299 файлами проекта установлен. Постоянная служба запущена, смена беседы подтверждена, но следующий запрос к долговременной памяти завершился продуктовым отказом до обращения к модели. Общая готовность продукта не установлена.

Для `/new` и `/approve` закрыты отдельные полные 180-секундные захваты. Root принял только фактическую границу новой беседы и пустой transcript. Каноническая приёмка receiver осталась `NOT_ESTABLISHED`; этот статус не заменён выводом Root. Успех границы не доказывает работу памяти.

Причина последующего отказа установлена в пределах проверенного профиля: native reset создал новую управляемую сессию без `account-origin`. Строгая проверка принадлежности данных вернула `ScopeDenied` до inference; затем обычная обработка и уведомление об ошибке также были отклонены. Вызов модели и ответ не подтверждены. Это отдельный дефект создания сессии; строгая защита account/profile сохранена. Глобальная блокировка других профилей из этого наблюдения не следует.

[Исправление reply-anchor карточки](../native-slash-confirm-anchor/README.md) прошло путь от принятого source к описанным установке и узкой пользовательской проверке. Отдельный tick-only кандидат 113R1 и вспомогательный source helper приняты только на уровне исходников и не установлены. Исправление происхождения новой управляемой сессии продолжается независимо; его установка и новый пользовательский результат здесь не заявляются.

Прежняя не привязанная к запросу карточка, исходные FAIL и UNKNOWN сохранены в их исходном объёме; закрытые попытки не повторялись. Результаты XLSX, контекста, даты и web на прежних версиях не являются проверками Source112. Workers, общая память, администрирование и полная релизная приёмка остаются открыты; startup READY не означает product READY.

[facts.json](facts.json) содержит те же факты с абстрактными метками закрытых доказательств. Этот пакет только публикует уже полученные результаты: новые продуктовые проверки не запускались. Частные пути, идентификаторы, пользовательский текст, сырые журналы и операционные скрипты исключены.
