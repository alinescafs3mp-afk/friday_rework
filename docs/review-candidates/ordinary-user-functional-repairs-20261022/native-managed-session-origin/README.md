# Принадлежность новой управляемой сессии

23.10.2026: **SOURCE_ACCEPTED_NOT_INSTALLED**. Пять производственных файлов исправлены поверх точных байтов Source112; независимое ревью и Root приняли этот source-компонент. Установка, фактическое восстановление повреждённой тестовой сессии и новый ответ к памяти пока не выполнены.

[Фактическая проверка Source112](../native112-actual-results/README.md) сначала подтвердила смену беседы через `/new` и `/approve`, затем выявила отказ обычного сообщения до inference. Причина: reset брал сохранённый `SessionSource`, у которого после JSON roundtrip намеренно нет живой identity/capability. Новая строка не получала `friday_account_origin`; строгая проверка всей профильной БД отклоняла её. Уведомление об ошибке тоже не проходило scope.

[Точный patch](native-managed-session-origin.patch) передаёт текущий допущенный source из явного reset и reset после исчерпания compression. Для управляемой сессии до INSERT проверяются текущая capability, платформа, account, профиль, transport, session key и путь собственной БД. Полная строка с проверенной принадлежностью записывается до публикации нового маршрута. Отказ INSERT сохраняет предшественника; suspended auto-reset соблюдает тот же порядок. Переход reset использует проверенное время рождения нативного successor, чтобы restart recovery не отвергал только что подготовленную пустую сессию. Это порядок согласованных записей, а не заявление об общей транзакции SQLite и JSON-маршрута.

Историческая metadata не становится capability. `check_database`, wire-сериализация identity, правила peer refresh и delegation не ослаблены. Отсутствующие, смешанные, чужие и отозванные основания остаются отказами; автоматический backfill не добавлен. Неуправляемая ветка сохраняет прежний контракт.

На финальных байтах 34 проверки с реальной изолированной SQLite прошли у автора и отдельно 34 у независимого reviewer. Исходная ошибка отдельно воспроизведена на baseline. Проверены обычное создание, явный и автоматический reset, restart/reopen, compression lineage, отказ INSERT, строгие отрицательные контроли, чужой successor и условное восстановление через нативные примитивы. Ещё 68 compatibility-регрессий относятся к снимку до последнего managed-only guard: их неизменная unmanaged область переиспользована, они не названы полным прогоном финального снимка. Открытых HIGH/MEDIUM нет; полного gate и живой приёмки из этого не следует.

[source-manifest.json](source-manifest.json) сохраняет точные пять before/after SHA, размер файлов, SHA validation harness и неизменных зависимостей авторизации. Последнее добавление к manifest содержит только проверенные хеши этих зависимостей; исходники, patch, тест и conditional operator recipe после независимого ревью не менялись. Validation harness и частные operational beforeimages не входят в публичный пакет. Patch и manifest опубликованы без изменения байтов.

Восстановление существующей плохой записи — отдельная ограниченная операция Root после штатного stop и резервной копии, с сохранением всей непустой истории и исходных отказов. Этот source-компонент исправляет будущие создания и не выдаёт ретроспективную принадлежность. Для следующей установки он объединяется с [принятым tick fix](../native-loop-tick-socket/README.md) в один Source113 revision2 поверх установленного112. Прежний tick-only113R1 не устанавливался и сохраняется как отдельный source-снимок. Общая память, workers, администрирование и полный релиз остаются открыты.
