Scoped XLSX extraction now appends inert JSON formula declarations from cells already included in its visible-sheet preview. Each record retains the sheet, actual cell reference, exact formula text and attributes, and saved-cache state, type and raw value. Missing, blank and present caches remain distinct, including present zero, boolean, error and string values. Missing or blank formula caches produce blank preview values. Shared/array followers remain declarations as saved; external references are text. There is no formula evaluation, recalculation or reconstruction.

This is a bounded preview, not a full-workbook formula inventory. Hidden sheets are excluded from cell/formula previews while their declared names remain in the existing inventory. Hidden rows and columns within visible sheets are retained. Preview limits are 5,000 row elements per sheet and 256 columns, with at most 512 formula records, 4,096 characters per formula/cache text field, 32,768 bytes per record and 128,000 bytes for the formula preview. Existing input, expanded-XML and extracted-output limits remain in force. Metadata explicitly reports skipped sheets, omitted rows/columns/records and truncated fields. Formula metadata stays on the existing string-compatible scoped carrier; generic XLSX extraction keeps its saved-value projection.
