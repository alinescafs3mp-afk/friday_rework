# CORE XLSX recalculation — source checkpoint

Apply `core.patch` after the Source98 DOCX/PDF delta. It changes three existing Hermes files, adds one XLSX recalculation helper and includes focused synthetic tests. This is reviewed source material, not an installer or a claim of runtime readiness.

`write_file(format="xlsx_recalculate")` takes a new `.xlsx` destination and JSON with exactly `source`, naming a workbook in the current user's own workspace. It runs the existing bounded local LibreOffice sandbox on a disposable cache-cleared copy, validates its formulas and literal cells, then transfers numeric formula caches into the original package. The source stays unchanged. Tables, names, formulas and unrelated parts are retained. Ordinary chart caches are refreshed; a string-only category encoded as `numRef` may become `strRef` with its range, series and axes retained. This adjustment is reported explicitly.

The existing file authority, source identity checks, create-only atomic publication, native cancellation and renderer cleanup are reused. Unsupported/active/external content, active workbook protection, unsupported formulas or charts, cycles, excessive expansion and incompatible engine output refuse publication. This is a conservative numeric-formula subset, not arbitrary Excel compatibility. Input/output is bounded to one million bytes; package and dependency limits remain enforced.

Source review includes a check against the actual retained user file and already completed external-engine output. It exposed inactive workbook-protection and absent chart-cache representations before installation; those are corrected. The original failures remain recorded. Nine final pure controls and both retained input variants pass. Twelve earlier synthetic controls included real isolated engine and scoped-route runs on the earlier source snapshot; they are historical evidence, not a fresh runtime run of this final revision. Fifteen final integration-preparation controls have their own scope and are not added to these overlapping counts.
