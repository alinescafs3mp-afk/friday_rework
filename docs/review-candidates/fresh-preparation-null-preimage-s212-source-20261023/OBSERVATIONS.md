# Наблюдения S212

Legacy `expected_base_files` с `null` ранее вызывал TypeError. Исправление переводит legacy и новый формат в явное описание отсутствующего preimage. Для существующего preimage сверяются hash, размер и логический mode; `lstat` отличает отсутствие от каталога, обычного или dangling symlink. Проверка вызывается непосредственно перед прежней проверкой и применением patch.

Некорректные digest/mode/path, дубликаты, несовместимая ancestry и prerequisites, удаление, rename и nonregular операции отклоняются. Историческое создание без явно заданного mode сохраняется.
