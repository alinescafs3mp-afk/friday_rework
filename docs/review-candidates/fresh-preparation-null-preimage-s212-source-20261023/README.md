# S212: null-preimage и проверка входов подготовки

Принятое исправление исходников от 23 октября 2026 года нормализует legacy `null` как отсутствие файла до применения patch и проверяет физическое состояние непосредственно перед существующим `git apply`. Это дельта только `scripts/hermes_prepare.py`.

[Патч](HERMES-PREPARE.patch) предназначен для точного исходного SHA-256 `8ccf3e259551e4b5f3e7c18c7e0b9379febf27a979c183c9713535d07e8ef0ac` (15 193 байта); результат — `5e28eaebef2f415458d0ecf2239ff03f049f6260a4e56d471b46d797c9db785b` (20 965 байт). Заголовки содержат только общие относительные пути. Применение и обратное применение проверены на собственной временной копии, её содержимое удалено. [SHA256SUMS](SHA256SUMS) закрепляет публикуемые файлы этого пакета.

[Наблюдения](OBSERVATIONS.md) отделяют проверку parser/preapply от полного fresh compose. Патч не описывает текущий установленный код и не создаёт native Source120. Физический обновлённый кандидат и его полный маршрут, установка, runtime и пользовательская приёмка здесь не выполнены. Интеграцию ведёт Root в существующем workflow.
