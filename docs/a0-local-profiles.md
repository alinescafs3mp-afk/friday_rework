# A0 local deployment profiles

`a0_deployment` is nonsecret explicit data in the existing Friday product/profile configuration. The native installation compiler retains it in the protected ordinary-user template. Operator worker preparation supplies the identical object as `runtime.a0.deployment`, plus an existing pinned network policy and the exact endpoint set. Rendering never installs a worker, creates a network or grants readiness.

The named `legacy-local-test` preset retains dispatcher at 40960 context / 4096 output and qwen3-embedding-0.6b on the original HTTP ports 8001/8002. Absent deployment data uses the original legacy path; existing presets/plans are not migrated or relabelled. `legacy_profile()` returns explicit data for selecting that preset.

An explicit alternative has exactly `name`, `preset` (native `Default`), `chat`, `utility`, `embedding`. Chat/utility each contain `endpoint`, `model`, `context_length`, `max_output_tokens`, `timeout`; embedding contains `endpoint`, `model`, `context_length` (zero preserves original unspecified context), `timeout`. Chat/utility may share a server or use distinct declared local servers. Embedding has a separate origin and the original OTHER scoped credential. These capacities are declarations requiring actual matching admission evidence, never availability claims or a hard total-prompt guarantee.

Only canonical HTTP(S) literal RFC1918/ULA endpoints with explicit ports and `/v1` are accepted. Loopback, link-local, special-use/public/cloud/DNS endpoints, userinfo, queries, fragments, interpolation, duplicate origins and implicit models refuse. No discover-models route or cloud fallback is added. A0 inference URLs do not configure web access: existing searxng-google A0 web inputs and scoped paid Exa Friday web remain separate.

The product compiler keeps the original chat join: model/endpoint/context/output must match explicit Friday inference and `FRIDAY_LLM_API_KEY`. A0 utility/embedding are independently selected in the same protected deployment object; their sources are not inherited from a historical test backend. Native model presets, network endpoint descriptors, worker input generation, runtime plan identity, startup probe and adapter admission consume the same renderer. Profile/runtime/source changes invalidate original runtime receipts and per-job route/plan proofs. Original deadlines, protected homes, generations, credentials, network namespaces and resource ownership still apply.

The tests include a labelled synthetic 262144/16384 profile with distinct utility and embedding routes. It proves producer/consumer data contracts against the actual pinned A0 preset reader and ModelConfig constructor; it does not prove that these synthetic models exist.

A0 deployment/reconciliation, mandatory useful-web contracts for both workers, kernel validation and all six live journeys remain unaccepted. The compiler still refuses enabling an A0 product runtime without its missing useful-web contract. Consumed G4 stays closed, kernel120 remains NOT_GRANTED_NOT_RUN, A0 and legacy Friday remain OFF. No live keys, network, model, package install, build, service or worker effects were performed here.
