# Source91: административная отмена после обычного пользовательского admission

Срез 29.10.2026, 06:11 МСК. Исправление сохраняет доступ подтверждённого администратора к исходному хранилищу и точной удержанной задаче после включения пользовательской изоляции. Полномочие ограничено синхронным status/pause/cancel: нативный provider повторно проверяет подписанную сессию, согласие и профиль; immutable identity задачи закрепляется до observation/stop/settlement. Новая работа и пользовательский UserScope этим путём не создаются. Исходные budget/deadline, stop intent, блокировки и CAS сохраняются.

`plugin.patch` содержит только адаптацию этого исправления к публичному host на указанном в SOURCE.json commit. `native.patch` сохраняет два точных исправленных native-файла в форме дельты. Патчи проверены прямым применением к точным before-images и сверкой конечных SHA. Восемь изолированных тестов с настоящими native auth/state/store и публичными plugin-consumers прошли; реальные worker observation/stop и supervision заменены явными inert fixtures. Принятое независимое source-review и прежние 2×8 проверок переиспользованы; сводка и ограничения находятся в CHECKS.json. Переносимая версия этих восьми тестов — `tests/native_admin_control_scope/`.

Это архив исходного исправления, а не подключение нового installer-слоя. Публичная native-цепочка не содержит всей установленной последовательности; применять native.patch можно только к точному before-image из SOURCE.json, вместе с plugin-дельтой и проверкой ближайших consumers. Снимок не заменяет активный host, не меняет установленную версию и не запускает сервисы. Приватный installation-specific bridge в user_worker_join, custody-материалы, данные пользователей и raw operational logs исключены.

Отдельно принята установка Source91/canonical H7/native N98 и проверка свежим процессом; Gateway и Dashboard работают под постоянным управлением без срока тестового окна. Эти факты не означают пользовательскую приёмку отмены: настоящий Telegram-сценарий отмены пока ожидает отдельной проверки. Engineering/A0 отложен, весь продукт ещё не READY; ранее принятый DSH coding-путь не повторялся ради публикации.
