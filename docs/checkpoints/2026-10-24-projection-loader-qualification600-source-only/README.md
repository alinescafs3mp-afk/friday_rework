# Принятые исходники: A0 projection loader и будущая qualification600

Архив содержит точные патчи принятого четырёхфайлового V2-среза и отдельного UNBOUND HTTP caller. Граница фактов — принятие объединённых исходников 24.10.2026 в 20:04:15 МСК и закреплённые в нём проверки. Пакет подготовлен для публикации Root из кэша; исходная точка main — `74c397b1a943e4c42c761423359d237ba052e55f`. Более поздние установка, исполнение и пользовательские результаты сюда не перенесены.

## Изменения

`host-runtime-projection-loader.patch` исправляет `a0_runtime_module` для загрузки в Dashboard projection namespace. Два точных legacy-импорта направляются к настоящим относительным helpers аутентифицированного вызывающего пакета. Только известная точная AST-форма `native_supervisor` заменяется ленивым вызовом настоящего конструктора; другая форма отвергается. SHA native-кода и проверки PROFILE/WEB/optional MEMORY сохранены. Глобальные `sys.path` и canonical module aliases не меняются.

Три патча qualification600 поднимают потолок квалификации с 300 до 600 с в `onboarding.py`, `user_worker_join.py` и `a0_bootstrap.py`. Эффективный бюджет ограничен меньшим из 600 и настроенных worker-бюджетов. Подготовка исходников, probes, наблюдение и публикация используют первоначальные часы. Лимит installation probe 300 с, отдельные job-бюджеты, reserve25 и native runtime/start/stop 120/45/20 с сохранены.

Патч `worker-join-qualification600-diagnostic-roots.patch` также добавляет две точные source/private-root строки в существующую таблицу безопасных диагностических меток. Все необходимые абсолютные пути сохранены побайтно как часть принятого кода. Они задают только метаданные расположения и не предоставляют доверие или доступ. Смена этих корней требует согласованного изменения таблицы; HTTP allowlist меток не меняется.

`http-qualification600-unbound.patch` согласует отдельный HTTP исходник: backend600, outer780, cleanup reserve120 и request610. State и prepare не меняются. Архивная цель `archive/worker-http/workers_http_once.FUTURE600.UNBOUND.py` обозначает исходник с незаданными operational bindings. Она не является установленным caller и не даёт права исполнять запросы.

## Целостность и публикация

`MANIFEST.json` задаёт точные SHA-256 before/after каждого файла и назначение архивных целей. Применение допустимо к собственной копии только при совпадении всего beforeimage. Пять патчей побайтно воспроизводят accepted after SHA; это проверка упаковки, без повторного исполнения продукта. Архив не является автоматическим overlay на отличающийся main. Файлы проверяются по `SHA256SUMS`.

В пакет не входят приватные input/evidence JSON, raw logs, handoff, operational планы/разрешения, credentials, аккаунтные идентификаторы, Telegram oracle или пользовательские файлы. Приватные свидетельства представлены только контрольными SHA. Дальнейшие публикация, установка и проверка текущих изменяемых свойств принадлежат Root.
